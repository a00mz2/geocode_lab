# مختبر العناوين — Geocode Lab

تطبيق Flutter لتصميم صيغة عرض أسماء المناطق من Google Geocoding وتجربتها على نقاط حقيقية.

**الفكرة:** تفحص نقطة ← يعرض لك كل مفتاح مع قيمته ← تختار وتلغي وترتّب وتضيف بادئات ← ترى الناتج مباشرة ← تنسخ كود Dart جاهزاً أو تثبّت القالب وتجرّبه على عشرات النقاط.

---

## التشغيل

### ١) فعّل الـ APIs في Google Cloud Console

من **APIs & Services → Library** فعّل:

- `Maps SDK for Android` (و `Maps SDK for iOS` إن لزم)
- `Geocoding API`
- `Places API` — اختياري، لخاصية «المعلم القريب» فقط

وتأكد أن **Billing** مفعّل، وإلا ترجع كل الطلبات `REQUEST_DENIED`.

### ٢) المفتاح في مكانين

- `lib/main.dart` → داخل `kMapsKey` في `defaultValue`
- `android/app/src/main/AndroidManifest.xml` → `com.google.android.geo.API_KEY`
  (وبدونه تظهر الخريطة رمادية)

أو بلا تعديل أي ملف:

```bash
flutter run --dart-define=MAPS_KEY=AIza...
```

### ٣) شغّل

```bash
flutter run
```

## الخريطة

| الإجراء | النتيجة |
|---|---|
| سحب الخريطة | الدبوس ثابت في المنتصف والخريطة تتحرك تحته |
| **نقرة** على أي مكان | ينتقل الدبوس إليه |
| **ضغطة مطوّلة** | ينتقل الدبوس **ويفحص فوراً** — أسرع طريقة للمسح |

| زر القمر الصناعي | تبديل بين الخريطة العادية والصور الجوية — مفيد لتمييز المعالم |

## بنّاء القالب — التبويب الأول

بعد أول فحص تظهر **كل** المفاتيح التي وفّرها الرد مع قيمها الفعلية:

```
☑ الشارع          شارع 881-63          [بادئة] ⣿
☑ الحي            الجهاد                       ⣿
☑ المنطقة         حي الجهاد                    ⣿
☐ المدينة         بغداد                        ⣿
☐ القضاء          الرشيد                       ⣿
☐ المحافظة ⚠      بغداد محافظة                 ⣿
☐ معلم قريب       —  (غير متوفر في هذه النقطة)
```

- **المربع** يفعّل الحقل أو يلغيه.
- **المقبض ⣿** يسحب الحقل لتغيير ترتيبه في السطر.
- **زر البادئة** يضيف نصاً قبل القيمة — `قرب ` للمعلم، `محلة ` للحي.
- **⚠** تعني حقلاً يُنصح بعدم عرضه للمستخدم (البلد، المحافظة، كود بلس).
- الحقول غير المتوفرة في النقطة الحالية تظهر رمادية وتُتجاهَل في الناتج.

فوقها شريط يضبط **الفاصل** (`، ` / ` - ` / مسافة / ` | `) ومفتاح **حذف التكرار** الذي يمنع `الجهاد، حي الجهاد` ويُبقي الصيغة الأشمل.

والمعاينة السوداء في الأعلى تتحدّث مع كل تغيير.

### الأزرار الثلاثة فوق المعاينة

| الزر | الوظيفة |
|---|---|
| 🗐 | نسخ الناتج النصي |
| `</>` | **نسخ كود Dart مستقل** — دالة واحدة + صنف مساعد بلا أي `import` أو package، مدخلها رد Geocoding الخام. تعمل في أي مشروع Dart/Flutter لا في هذا التطبيق فقط |
| 📌 | حفظ نسخة كقالب جديد |

### استعمال الكود في مشروع آخر

الكود الذي ينسخه `</>` **لا يعرف شيئاً عن هذا التطبيق**: لا `PlaceLocation` ولا Dio ولا Flutter.
الصقه في ملف مستقل (مثل `lib/address_format.dart`) ثم:

```dart
// استدعِ Geocoding API بأي عميل (http / dio) وفكّ الرد:
final body = jsonDecode(response) as Map<String, dynamic>;

// اسم الدالة من اسم القالب — الأسماء العربية تعطي formatAddress
final line = formatAddress(body);
Text(line);
```

- **`poi`** (اختياري): اسم المعلم القريب من Places API. **`areaHint`/`areaHintSource`** (اختياريان): اسم منطقة من نقطة مجاورة ومسافتها. **`lat`/`lng`**: إحداثية الاستعلام. تظهر هذه المعاملات في توقيع الدالة **فقط** إذا كان القالب يستعمل مفاتيح تحتاجها.
- **إن كان مفتاح `POI` أو `جوار` مفعّلاً في الشريط** عند الضغط على `</>` (والقالب يحتاجهما)، يُضاف إلى الكود نفسه ما يجلبهما: دالة `fetchFormatAddress(lat, lng, apiKey: …)` تستدعي Geocoding، ثم Places Nearby للمعلم بنفس منطق `pickBestPoi`، ثم الجوار (أربع نقاط على 250م ثم 700م) عند غياب اسم المنطقة، تماماً كما يفعل زر «افحص». تحتاج `dart:io` فقط من الـ SDK (لا package)، ولذلك لا تعمل على Web. من دون المفتاحين يبقى الكود بلا أي استيراد ويأخذ رد Geocoding جاهزاً.
- الناتج **يطابق معاينة القالب حرفياً**: اختبار المطابقة في `test/standalone_code_test.dart` يكتب الكود المولَّد في ملف خارج المشروع، ويمرّره على `dart analyze --fatal-infos`، ويشغّله بـ `dart run`، ويقارن ناتجه بـ `render()` على كل مفتاح وكل سيناريو.
- الصنف المساعد `_GeoFields` **واحد لكل القوالب**: عند لصق أكثر من قالب في ملف واحد أبقِ نسخة واحدة منه.

## القوالب — التبويب الثاني

كل قالب محفوظ يُعرض مع **ناتجه على النقطة الحالية**، فتقارن الصيغ جنباً إلى جنب:

```
سطر السائق     شارع 881-63، حي الجهاد
مختصر          حي الجهاد
مع المعلم      شارع 881-63، حي الجهاد، قرب جامع مصطفى
```

انقر أي قالب ليصبح النشط في البنّاء. من قائمة `⋮`: نسخ الناتج، نسخ الكود، إعادة تسمية، تكرار، حذف.

القوالب **تُحفظ على الجهاز** (`shared_preferences`) وتبقى بعد إغلاق التطبيق، وتعدّلها في أي وقت.

عند فحص نقطة في منطقة جديدة تحمل مفاتيح لم تظهر سابقاً (`airport`, `natural_feature`…) تُضاف تلقائياً لكل القوالب **مطفأة**، فتبقى متاحة للاختيار بلا أن تغيّر نتائجك الحالية.

## JSON — التبويب الثالث

ملخّص آخر نقطة: الحالة، عدد النتائج، كل مفتاح وقيمته، وناتج كل قالب:

```
════ حي الجهاد 33.28697, 44.29910
status : OK   results: 10
route                       : شارع 881-63
neighborhood                : الجهاد
sublocality_level_1         : حي الجهاد
locality                    : بغداد
administrative_area_level_2 : الرشيد
⟦سطر السائق⟧ شارع 881-63، حي الجهاد
⟦مختصر⟧ حي الجهاد
```

زر 🗐 في الشريط العلوي ينسخ **كل** ما فحصته في الجلسة — هذا ما ترسله للتحليل.

---

## المنطق الأساسي

1. **امسح كل النتائج، لا `results[0]`.** الرد يحوي ١٠ نتائج من الأخص للأعم؛ الـ `neighborhood` قد يظهر في النتيجة الخامسة فقط.
2. **أول ظهور لكل `type` هو الأدق** — `putIfAbsent` على خريطة واحدة.
3. **الشوارع الرقمية:** `881-63` تصبح `شارع 881-63`.
4. **التكرار بالاحتواء:** `الجهاد` + `حي الجهاد` ⇒ تبقى الصيغة الأشمل.
5. **لا فواصل معلّقة:** الحقل الفارغ يُحذف هو وفاصله.

## الاختبارات

```bash
flutter test
```

٥٥ اختباراً في ملفَين:

- `test/place_location_test.dart` — على ردود حقيقية من حي الجهاد ومدينة الصدر: التقاط الحقول من نتائج متأخرة، حذف البلد والمحافظة، دمج التكرار، البادئات، الفواصل، القيم البديلة، الاسم المضمون، والتخزين.
- `test/standalone_code_test.dart` — **مطابقة الكود المولَّد**: يولّد قالباً لكل مفتاح في `fields` وكل القوالب الافتراضية وتوليفات الفاصل وحذف التكرار والبادئات العدائية، يكتبها في ملف Dart خارج المشروع، يمرّره على `dart analyze --fatal-infos`، يشغّله بـ `dart run`، ويقارن كل ناتج بـ `render()`. أي انحراف بين الكود المنسوخ والمعاينة يُكسر هذا الاختبار.

## مناطق تستحق الاختبار

| الحالة | ما تكشفه |
|---|---|
| حي معروف (الكرادة، المنصور) | الحالة المثالية |
| مدينة الصدر | قطاعات وشوارع مرقّمة |
| أطراف بغداد / أرض زراعية | غياب `route` و `neighborhood` معاً |
| طريق سريع | `route` قوي بلا حي |
| قرب مول أو مستشفى | جودة الـ POI |
| البصرة، الموصل، كربلاء | تغيّر `locality` |
| أربيل، السليمانية | أسماء كردية رغم `language=ar` |

## ملاحظات

- **`googleDio` منفصل عمداً** بلا Interceptors. لا تمرّر عليه Interceptor تطبيقك، وإلا أُرسل توكن المستخدم (`Authorization: Bearer`) إلى خوادم Google.
- **قيّد المفتاح** من Cloud Console: SHA-1 + package name للأندرويد، و API restrictions على الثلاثة المذكورة فقط.
- **الكلفة:** كل فحص = طلب Geocoding مُحاسَب، و`POI` يضيف طلب Places أغلى بمراحل.
